# CIC-000-002 — Canonical Identifier Standard

## 1. Identifier classes

| Class | Purpose | Format (ABNF in §2) | Example |
|-------|---------|---------------------|---------|
| Instance ID | Runtime aggregate instance | `ulid` | `01J9Z3K8Q4N6XG2W7T5R0VYB1C` |
| Instance URN | Globally qualified instance reference | `urn:ucos:<tenant>:<kind>:<ulid>` | `urn:ucos:acme:co:01J9Z3K8Q4N6XG2W7T5R0VYB1C` |
| Metadata URN | Versioned metadata definition | `urn:ucos:<namespace>:<kind>:<name>[@<semver>]` | `urn:ucos:ucos.std:type:Subscription@2.1.0` |
| Artifact ID | Corpus artifact | `CIC-<NNN>-<NNN>` | `CIC-011-001` |
| Domain ID | Constitutional domain | `DOM-<CODE>` (3–5 upper letters) | `DOM-PRC` |
| Principle ID | Constitutional principle | `PRIN-<NNN>` | `PRIN-006` |
| Rule IDs | Certification / validation rule | `CR-<NNN>-<NNN>-<NN>` / `VR-…` | `CR-011-001-03` |
| Event type | Domain event type | `ucos.<context>.<aggregate>.<event>.v<major>` | `ucos.catalog.offer.published.v1` |
| External ID | Identifier issued by another system | `ExternalReference{scheme, issuer, value}` | `{gs1:gtin, GS1, 09506000134352}` |

## 2. Grammar (ABNF, RFC 5234)

```
ulid        = 26(%x30-39 / %x41-48 / %x4A-4B / %x4D-4E / %x50-54 / %x56-5A) ; Crockford base32
tenant      = 1*63(lc / DIGIT / "-")
namespace   = segment *("." segment)               ; reverse-DNS style, e.g. ucos.std, com.acme.telco
segment     = lc *(lc / DIGIT / "-")
kind        = lc *(lc / DIGIT / "-")               ; registered in kind registry (§4)
name        = ALPHA *(ALPHA / DIGIT / "_" / "-")
semver      = 1*DIGIT "." 1*DIGIT "." 1*DIGIT ["-" prerelease]
lc          = %x61-7A
```

## 3. Rules

1. Instance IDs MUST be ULIDs generated by the owning service at command acceptance; clients MAY propose
   an ID in `Idempotency-Key`-protected create commands (client-generated ULID) — the service MUST
   reject proposals whose timestamp component deviates > 5 minutes from server time.
2. IDs are opaque. Consumers MUST NOT parse semantics from them except the ULID timestamp for
   partition routing.
3. IDs are never reused, including after hard deletion (crypto-shred for privacy, CIC-014).
4. Metadata URNs without `@semver` denote "latest active version in the requesting context";
   persisted references MUST store the pinned version.
5. External identifiers are never primary keys; they are stored as `ExternalReference` value objects
   owned by DOM-REF and are unique per `(tenant, scheme, issuer, value)`.
6. Region: the ULID is region-agnostic; the aggregate's `homeRegion` is recorded in its envelope, never
   encoded in the ID (supports re-homing, PRIN-015).

## 4. Kind registry (kernel kinds; extensions register via CORPUS-029)

`party, org, identity, credential, type, attr, facet, reltype, co, rel, dim, scope, policy, rule,
decision, lifecycle, event, evidence, taxonomy, term, changeset, cert, plugin, pack, doc, media`.

## 5. Certification Rules

- **CR-000-002-01** Property test: 10⁶ generated IDs per service contain no duplicates and are lexicographically monotonic per generator within the same millisecond.
- **CR-000-002-02** Contract test: every API response field typed as reference matches `urn:ucos:` grammar.

## 6. Validation Rules

- **VR-000-002-01** Every `kind` used in any URN appears in §4 or in a certified pack's kind registry.
- **VR-000-002-02** Every event type string matches `^ucos\.[a-z0-9-]+\.[a-z0-9-]+\.[a-z0-9-]+\.v[0-9]+$`.
- **VR-000-002-03** Every Domain ID matches `^DOM-[A-Z]{3,5}$` and is unique in the registry.
